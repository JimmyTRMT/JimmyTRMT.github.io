## About me

I'm Jimmy Tremouillault, a backend and analytics engineer based near Toulon, France.

For three years I've been an apprentice developer at Paprec Énergie, building web tooling and production data pipelines for a network of 30+ waste-to-energy plants. Most of my work sits between the plant floor and the database: Grafana panels querying an industrial historian through SQL Server, a Python generator that turns an Excel config sheet into ready-to-paste dashboard code, Power BI reports connected to production data, and an internal Angular application the sites use every day.

I also spent twelve weeks at Kasetsart University in Thailand, where I built a self-hosted Flask platform for annotating images and exporting GLCM texture features for machine learning.

I'm finishing an engineering degree in Digital Systems at SeaTech, University of Toulon, and I'm looking for a junior backend or analytics engineering role in a remote-first team from October 2027. I work remotely only.
