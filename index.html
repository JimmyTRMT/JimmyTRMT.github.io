● in productionAVEVA Historiansafety

Turning a raw pressure reading into a safety event

These panels do not read a signal that says "explosion detected". They take an ordinary analogue measurement, a pressure in mBar or a CO concentration, and compare it to a threshold. The conclusion is derived, not measured.

The filtering happens in SQL Server before a single row leaves the server, timestamps are pinned to UTC on both sides to stop the browser silently shifting an hour, and the render logic finds columns by name and type so it survives Grafana reordering them. I documented the threshold as the fragile part, because a badly calibrated one changes what counts as an event with nothing to signal it.

● in productionshift dashboard v2

One measurement, three ways to read it

Operators needed the current shift at a glance and yesterday for comparison. For each quantity, three panels share the same source: an instant value, the current day against a fixed threshold line, and the previous day with its own average drawn across it.

That flat average line is a CROSS JOIN with no join condition, replicating a single aggregate across every row of the series, with a field override hiding the column that only exists to carry it.

An annotation platform for a research department

Twelve weeks at Kasetsart University, Sakon Nakhon. The department depended on public datasets because it had no way to build its own. I shipped a self-hosted Flask platform to annotate retinal fundus and waste-sorting images and export GLCM texture features for machine learning.

Application factory, five blueprints with an identical shape, guards on before_request rather than per route, CSRF on every POST, and a fail-fast boot that refuses to start on a default secret key. The export pipeline computes 24 GLCM texture features per image and never returns a 500: a corrupt file costs one zero-filled row and a log line, not the batch.

Deployed on a lab machine over LAN with Waitress so several annotators could work at once. Delivered with English and French documentation and a conference paper in LNCS format.
